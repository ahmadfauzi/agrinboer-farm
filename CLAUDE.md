# CLAUDE.md

Repo ini berisi landing page Agrin Boer Farm (peternakan kambing keluarga, Tajinan, Malang).

- Project landing page: `Landing Page Project/agrin-boer-farm/`. Mulai setiap sesi dari `project.md` di folder itu.
- Sumber brand: `Landing Page Project/agrin-boer-farm/brand-strategy.md`.
- Stack: satu `index.html` + `tokens.css` (CSS biasa, tanpa Tailwind, tanpa build step). Tempat deploy: Cloudflare Pages, output directory `site/`.
- File publik HANYA di `site/`. Dokumen kerja (brief, copy, strategi, catatan) tetap di folder project dan tidak boleh disalin ke `site/`.
- Skill alur: landing-page-builder (orkestrator), landing-page-blueprint, prd-creator, copywriting-assistant, antislop-copy-id, arah-visual-web-id, design-system-creator, impeccable.
- Jangan mengarang data: harga, nomor WA, testimoni, angka, sertifikat. Nilai dummy hanya bila pengguna minta, ditandai `data-dummy`, dan dicatat sebagai penghalang deploy.
- Jangan klaim "Boer murni", halal, atau pemeriksaan kesehatan sampai buktinya ada.
- Bahasa: Indonesia.
